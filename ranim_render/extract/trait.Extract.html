Expand description

Extract an evaluated value into render-world entities or resources.

Implementations can recurse into other values using the same context. Each call to ExtractContext::entity claims the next persistent output of the source frame item. Outputs no longer claimed on the next extraction are despawned automatically. Entities created directly through ExtractContext::world_mut remain the implementation’s responsibility.
