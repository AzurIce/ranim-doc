RanimItemsPluginrender
Installs the built-in render plugins: camera frame, vector items, and mesh items. This is what the default render setup of a project binary uses; install it explicitly when composing a custom RenderSetup with additional extraction plugins, and do not combine it with the individual plugins (they are unique in a bevy app).
