pub struct Line {
    pub points: [DVec3; 2],

    pub stroke_rgba: AlphaColor<Srgb>,

}
Expand description

A line segment.

Fields§

§points: [DVec3; 2]

The start and end points of the line.

§extrude: [f64; 2]

The distance two endpoints extends or shrinks from its original position. Positive value means extension and negative value means shrinking.

§stroke_rgba: AlphaColor<Srgb>

Stroke RGBA values.

§stroke_width: f32

Stroke width.
