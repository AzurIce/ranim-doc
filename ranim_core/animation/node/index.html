Runtime animation nodes and their interpreters. Runtime animation nodes and their interpreters.

This is the closed core of the animation tree: NodeContent is the runtime vocabulary (children or a leaf), AnimNode wraps it with the timing shell, and all structural traversals — visual evaluation, seal-time audio baking, and preview introspection — live here.

Authoring sugar (AnimSequence, AnimStack, AnimLagged) is layered on top in crate::animation::compose; user leaf protocols live in crate::animation::eval.
