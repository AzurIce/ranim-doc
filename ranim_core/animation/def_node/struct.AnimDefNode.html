Expand description

A retained authoring node that can repeatedly build a runtime AnimNode.

Children carry explicit local placements, not sequence or stagger rules. Editing one child does not move its siblings. Optional playback fields are overrides: an unspecified field preserves the recipe’s own default. Containers retain their authored spans, including trailing gaps.

Fields§

§content: AnimDefNodeContent

Retained child definitions or an erased complete leaf definition.

§time_range: Option<Range<f64>>

Optional parent-time window. Changing it remaps content, not child placement.

§rate_func: Option<AnimDefRate>

Optional rate override; None preserves the recipe’s mapping.

§enabled: Option<bool>

Optional enable override; None preserves the recipe’s value.

§internal_time_secs: Option<f64>

Explicit content span for a branch, including authored trailing gaps.

§end_inclusive: Option<bool>

Optional right-endpoint inclusion override, resolved by sequence composition.

§anim_name: Option<&'static str>

Optional authoring name for containers and generated definitions.

pub fn build(&self) -> AnimNode

Build a fresh runtime tree, retaining inputs, recipes, and child definitions.

A branch’s natural content span is 0..max(child.time_range.end), unless an authored content span preserves additional gaps. An explicit window remaps that span without changing its children’s times.

§Panics

Panics if an effective window or content span is non-finite or has negative duration.
