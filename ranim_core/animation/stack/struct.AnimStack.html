Struct AnimStack 

Source 
pub struct AnimStack {
    animations: Vec<AnimationCell>,
    duration_secs: f64,
}
Expand description

Dynamic overlay animation container.

Unlike AnimSequence, every pushed animation keeps its own local start time and the stack duration is the maximum child extent.
