Struct Sound 

Source 
pub struct Sound {
    track: AudioTrack,
}
Expand description

An audio leaf: plays a clip’s span inside its placed window.

Authored with Sound::new plus the track shapers (with_gain, with_fade_in, …), then composed exactly like a visual animation:

ⓘ
seq![
    square.fade_in(),
    Sound::new(narration),          // plays while the next cells run
    square.write(),
]
