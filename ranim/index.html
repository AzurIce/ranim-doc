Ranim is an animation engine written in rust based on wgpu, inspired by 3b1b/manim and jkjkil4/JAnim.

§Coordinate System

Ranim’s coordinate system is right-handed coordinate:

     +Y
     |
     |
     +----- +X
   /
+Z
